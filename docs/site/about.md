# About

Reference copy of what `/about` serves. The published text lives in
`src/platforms/web/app/src/content/about.md` and is rendered by `<Doc/>`; there is no second copy
here to fall behind it.

## Why this file holds no copy

It used to. It was the pre-launch draft — `# About — Page Content Draft`, hero and subhead, bracket
placeholders where the contact addresses go — and the shipped page moved past it. By the time the
two were read side by side the draft was claiming, of a product that had shipped, that you can
"fund and use Noema anonymously, with no email and no wallet linkage": half true, and the false
half is the half a reader acts on. Crypto funding does leave a link — the depositing address
reaches us through the deposit provider and is retained for sanctions screening — and the shipped
page says so.

A draft that keeps its own copy of a claim is a place the claim can go stale unwatched. This
repository is public, so a stale claim here is a published one. Edit the content file.
